# 🛒 Mini E-Commerce App

A modern, responsive, and interactive E-Commerce web application built with **ReactJS** and **Tailwind CSS**. Features dynamic product filtering, real-time search with history, and an interactive shopping cart.

![TailwindCSS](https://img.shields.io/badge/Tailwind_CSS-38B2AC?style=for-the-badge&logo=tailwind-css&logoColor=white)
![Vite](https://img.shields.io/badge/Vite-646CFF?style=for-the-badge&logo=vite&logoColor=white)

---

## ✨ Features

- 🔍 **Smart Search & History:** Quick search modal with autocomplete and local search history management.
- 🏷️ **Dynamic Category Filter:** Seamlessly filter products based on trending categories.
- 🛒 **Interactive Shopping Cart:** Real-time cart quantity adjustment, total price calculation, and item removal.
- 📱 **Mobile First & Responsive:** Clean UI optimized for both Desktop and Mobile viewports.

---

## 🛠️ Tech Stack

- **Frontend Framework:** React.js (Hooks, State Management)
- **Styling:** Tailwind CSS
- **Icons:** Lucide React / Heroicons / Inline SVG
- **Code Formatter:** Prettier & Prettier Tailwind Plugin
- **Build Tool:** Vite
