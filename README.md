# 🛒 Mini E-Commerce App

🌐 **Live Demo:** [react-ecommerce-mini.vercel.app](https://react-ecommerce-mini.vercel.app)

A modern, responsive, and interactive E-Commerce web application built with **ReactJS**, **Zustand**, **React Router**, and **Tailwind CSS**. Features dynamic URL-based product filtering & sorting, real-time search with history, and an interactive shopping cart.

## ✨ Features

- 🔗 **URL-Based Filtering & Sorting:** Fully synchronized search query parameters (`q`) and sorting options (`sortBy`) in the URL for seamless state management and shareable links.
- 🔍 **Smart Search & History:** Quick search modal with autocomplete and local search history management.
- 🏷️ **Dynamic Category Filter:** Seamlessly filter products based on trending categories.
- 🛒 **Interactive Shopping Cart:** Real-time cart quantity adjustment, total price calculation, item selection, and checkout simulation.
- 📱 **Mobile First & Responsive:** Clean UI optimized for both Desktop and Mobile viewports with custom mobile modal navigation.

---

## 🛠️ Tech Stack

- **Frontend Framework:** React.js (Hooks, React Router DOM v6)
- **State Management:** Zustand
- **Styling:** Tailwind CSS
- **Build Tool:** Vite
- **Code Formatter:** Prettier & Prettier Tailwind Plugin
